# 🌌 AetherMap — Master Tabletop Projection & Dual-Screen VTT System

> **Высокопроизводительная система проецирования боевых карт и управления настольными ролевыми играми (D&D 5e, Pathfinder 2e, Cyberpunk RED, Call of Cthulhu, Savage Worlds и др.) для офлайн-игр за физическим столом с ТВ или проектором.**

---

## 🎯 Для чего создана AetherMap?

При игре за реальным столом с **интерактивным столом (встроенным горизонтальным телевизором)** или **потолочным проектором** мастеру необходима система, которая разделяет интерфейс на две независимые роли:

1. **Экран Мастера (Master DM Control Workspace)**:
   - Бесконечный холст в стиле Miro, где размещаются все боевые сцены, таверны, подземелья, справочники, токены, генераторы инициативы и аудиомикшер.
   - Мастер видит всё: скрытые комнаты под туманом войны, невидимые ловушки, показатели здоровья монстров и заметки к комнатам.
   - Полный контроль над интерактивной рамкой обзора игроков: перемещение, масштабирование, поворот (0°/90°/180°/270°), блокировка и мгновенный перевод внимания (Camera Focus).

2. **Окно Игроков (Player Screen / TV / Projector Display)**:
   - Полностью чистый, кинематографичный экран без лишних панелей управления, кнопок и меню.
   - Выводится на ТВ/проектор в полноэкранном режиме (F11 / кнопка разворота).
   - Игроки видят только то, что открыл мастер: честный туман войны, анимированные эффекты стихий (огонь, вода, кислота, пар), динамические шаблоны заклинаний и атмосферный блэкаут.

## ✨ Ключевые возможности

### 🎲 Встроенная система процедурных генераторов (Procedural Generators)
- **Генератор городов (City Generator)** — моментальная генерация детальных карт средневековых и фэнтезийных городов с кварталами, стенами и замками.
- **Генератор подземелий (Dungeon Generator)** — создание многокомнатных подземелий с туманом войны, сеткой и описанием комнат.
- **Генератор особняков и домов (Dwellings / House Generator)** — поэтажные планы жилых домов, поместий и замков с экспортом каждого этажа.
- **Генератор таверн (Tavern Generator)** — атмосферные планы заведений с расстановкой мебели, комнат и названием.
- **Генератор деревень (Village Generator)** — процедурные сельские поселения и хутора.
- **Генератор NPC, сокровищ, лута и торговцев** — встроенный генератор случайных встреч, волшебных предметов, торговцев и их ассортимента.

### 🗺️ Бесконечный холст и менеджер боевых карт (Multi-Map Canvas)
- **Любые медиаформаты**: Поддержка статичных изображений (`JPG`, `PNG`, `WebP`) и живых анимированных карт (`MP4`, `WebM`) с плавной зацикленной анимацией и аппаратным ускорением.
- **Интерактивная рамка камеры игроков**: Зеленая рамка на холсте мастера наглядно показывает границы экрана ТВ/проектора игроков. Мастер может перемещать и масштабировать её на лету или активировать авто-следование за активной картой.
- **Поддержка калибровки сетки**: Квадратная и гексагональная сетка с настройкой PPI, смещения (Offset) и автоопределением шага сетки.

### 🌫️ Процедурный туман войны (Fog of War & Raycasting)
- **Движок на Rust**: Быстрое стирание и восстановление тумана кистями разных радиусов с нулевой задержкой.
- **Текстурный шум и темы**: Процедурный дым и туман (Realistic Mist, Ethereal Ghost, Toxic Poison, Pitch Dark).
- **Скрытие/Открытие выделением**: Открытие комнат прямоугольником или полигоном в один клик.

### 🔥 Интерактивная магия и физика стихий (Elemental Physics)
- **Живые эффекты прямо на карте**: Размещение анимаций огня, разлитой воды, ядовитых кислотных луж, мистического дыма и молний.
- **Взаимодействие стихий**: Вода тушит огонь с физическим испарением и клубами пара.
- **Шаблоны заклинаний**: Круги (Fireball), конусы (Burning Hands), линии (Lightning Bolt) и кубы по правилам D&D 5e с точным расчётом покрытия сетки.

### ⚔️ Боевой трекер и инициатива (Combat & Initiative Tracker)
- Учёт раундов, показателей HP, AC, временных очков здоровья и статусов состояний.
- Быстрая сортировка инициативы, поддержка кубиков и скрытых монстров (невидимых для игроков до момента нападения).

### 🎲 3D / Пространственные броски кубиков (Spatial Dice Engine)
- Расчёт вероятностей и честные броски любых дайсов (d4, d6, d8, d10, d12, d20, d100, пулы костей).
- Статистический анализ распределений методом Монте-Карло на Rust.

### 🎵 8-канальный аудиомикшер и звуковая атмосфера (Soundscape Mixer)
- Фоновая музыка, звуки погоды (дождь, ветер, метель), звуки таверны и боевые звуковые эффекты (SFX).
- Пространственное позиционирование звуков.

### 📁 Единая локальная папка ассетов (Unified Asset Folder)
- Привязка реальной папки с жесткого диска компьютера.
- Автоматическая сортировка на подпапки `maps/`, `tracks/`, `props/`, `sfx/`.
- Долговечное сохранение привязки в IndexedDB без необходимости повторного выбора.
- 1-клик ручная синхронизация по кнопке в верхней панели и в модальных окнах.

## 🚀 Установка и запуск

### Вариант 1. Скачать готовый релиз (Desktop App)
Перейдите на страницу [**Releases**](../../releases) и скачайте сборку под вашу систему:
- **macOS (Universal 2: Intel + Apple Silicon M1/M2/M3/M4)**: `AetherMap_x.x.x_universal.dmg` (работает на любых Mac)
- **Windows**: `AetherMap_x64.msi` или портативный `.exe`
- **Linux**: `AetherMap_amd64.AppImage` или `.deb`

#### 🍎 Примечание для пользователей macOS:
Если при первом запуске macOS выдает сообщение `«AetherMap» повреждена и её невозможно открыть` (стандартное поведение Gatekeeper для открытых релизов без платного сертификата Apple):
1. Переместите приложение в `/Applications` («Программы»).
2. Выполните в Терминале:
   ```bash
   xattr -cr /Applications/AetherMap.app
   ```
3. *Или:* Кликните правой кнопкой мыши по приложению в Finder и выберите **«Открыть»** -> **«Открыть»**.

### Вариант 2. Запуск из исходного кода (Разработка)

#### Требования:
- **Node.js**: v20 или выше
- **Rust**: 1.75+ (`rustup default stable`)
- **Tauri CLI** (устанавливается автоматически с npm dependencies)

#### Шаги установки:
```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/aethermap.git
cd aethermap

# 2. Установить зависимости
npm install

# 3. Запустить в режиме разработки (Web + Server)
npm run dev

# 4. Запустить нативное десктопное приложение Tauri (Rust + Webview)
npm run tauri dev
```

## 🛠️ Сборка бинарных файлов (Build)

### Локальная сборка:
```bash
# Генерация оптимизированных релизных бинарников для вашей ОС:
npm run tauri build
```
Готовые исполняемые файлы будут помещены в директорию `src-tauri/target/release/bundle/`.

### Автоматическая сборка в GitHub Actions:
В проект встроен готовый CI/CD пайплайн (`.github/workflows/release.yml`). 
При каждом `git push` в ветки `main`/`master` или создании тега `v*` GitHub автоматически:
1. Вычисляет версию проекта.
2. Собирает нативные бинарники под **Windows (x64)**, **macOS (Intel/Apple Silicon)** и **Linux (AppImage/deb)**.
3. Публикует готовый релиз со всеми файлами в разделе **Releases** вашего репозитория.

## ⚡ Оптимизация для слабого железа

AetherMap специально спроектирован для работы прямо за игровым столом на ноутбуках со встроенной графикой (Intel HD Graphics, AMD Radeon Vega) и планшетах:
- **Вычисления на Rust**: Тяжелая математика (трассировка лучей, геометрия сетки, проверка коллизий, шум тумана) скомпилирована в нативный машинный код.
- **TypedArray & Object Pooling**: Рендеринг сотен частиц и заклинаний без аллокаций памяти и пауз Garbage Collector (стабильные 60 FPS).
- **GPU-accelerated Canvas & Video**: Аппаратное ускорение декодирования видеокарт и рендеринга слоев.
